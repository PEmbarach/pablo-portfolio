# Pablo Embarach — Portfolio

Full stack personal portfolio site.

**Stack:** Angular 21 + Ionic (frontend) · Spring Boot 3 / Java 23 (backend)
**Hosted:** Self-hosted on Fedora via Nginx + DuckDNS + Let's Encrypt

## Structure
- `/frontend` — Angular + Ionic SPA
- `/backend`  — Spring Boot REST API (contact form → Gmail SMTP)

## Local development
- Frontend: `cd frontend && ionic serve`
- Backend: `cd backend && mvn spring-boot:run`
